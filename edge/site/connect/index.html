Connect an assistant

Let an AI assistant create and manage your instances. SIROS ID Dev is an MCP server: add its address to a client that supports remote MCP servers and approve the connection in the console.

The address

https://console.@DOMAIN@/mcp

Claude Code

claude mcp add --transport http sirosid https://console.@DOMAIN@/mcp

The first time it is used, the client opens your browser. Sign in with your passkey if asked, check which application is asking, and choose Allow.

Other clients

Any client that supports remote (HTTP) MCP servers with OAuth works: it registers itself, sends you to the console to approve, and gets a token. There is nothing to copy and paste.

What it can do

  • List the starting-point templates and your saved configurations, validate a configuration and save it.
  • Create, inspect, stop, start, reset, keep and destroy your instances.
  • Read an instance's admin credentials when you ask for them.

It cannot create invites, see other people's data, touch your passkeys or change your account. It uses the same rules as the console: your limits, your permissions and your ownership checks apply exactly as they do when you click.

Staying in control

  • Access lasts up to eight hours, and ends sooner if you revoke it under Connected applications in the console or if the service restarts.
  • Anyone can register an application under any name, so check the address your browser is sent to before you allow it.
  • Text that an assistant reads from your instances can come from outside. Treat what it does after reading untrusted text with the same care as anything else it does.
SIROS ID Dev is a test and development service run by the SIROS Foundation. It is not a production service and carries no availability or data-retention promise. Access is by invitation.
