How it works

Four steps from an invite to a running instance.

  1. Register. Open the console, choose Register and enter your invite token. You create a passkey, and it must support the WebAuthn PRF extension (recent security keys and most current platform passkeys do). Add a second passkey on a different device or key afterwards: there is no account recovery.
  2. Choose a configuration. On the Configs tab, start from a template and adjust it. The editor checks the configuration for you and lists every problem at once.
  3. Create an instance. Pick a configuration on the Instances tab and press create. The first deployment takes a few minutes; the card shows its progress and, when it is running, the addresses of the wallet, issuer, verifier and the rest.
  4. Test, then stop or discard. Use the addresses from the console in your wallet, issuer or verifier. Stop an instance to pause it, reset it to erase its data, or destroy it. Anything left alone is removed after three days.

vc-registryThe credential type registry.
mini-oidcA test login provider that stands in for a government identity provider.

Limits

By default each person can run two instances at once, and an instance lives for three days. Some people have a keep allowance that lets chosen instances outlive that. A stopped instance starts again within a minute or so.
